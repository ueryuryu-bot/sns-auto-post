[No.1] 危険警告型

新築木造アパート。
表面利回り8%。
融資30年。

実は危ない。

理由：木造は築20年で資産価値がほぼゼロになるのに、
ローン残債が3000万残ってる状況が起きる。
20年後売却しても融資返済できず
赤字処理。

新築高利回りは
「建築詐欺」の入り口だったりする。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.2] 業界本音型

不動産会社が絶対に言わない言葉
「この物件、
 ローン返済が終わる30年後に
 建て替えが必要です」

なぜか。売ったら責任が発生するから。

だから投資家は
ローン完済後の出口戦略まで
自分で計算しなきゃいけないんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.4] 初心者罠型

投資初心者が誤りがちなこと。

「利回りが高い＝儲かる」

違う。

利回り8% − 空室率20% − 管理費 − 修繕費 − 税金
＝ 実質手取り2%とかザラ。

広告の利回りと
手取り利回りは全然違う。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.5] 融資・ファイナンス型

融資を断られる人の共通点。

年収の25倍以上の
融資申請をしてる。

銀行の返済比率（年収に対する返済額の割合）は
大体35%が上限。

年収600万なら
最大融資額は5000万前後。
それ以上の積み上げは…難しい。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.6] 利回りの罠型

「表面利回り」と「実質利回り」の差。

表面利回り＝年間賃料 ÷ 購入価格

でも実際は
− 空室期間
− 修繕費（年5〜10万）
− 管理費
− 税金

を引く。

5%表面利回りなら
実質は1〜2%。
銀行預金の方がマシなんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.8] 売却タイミング型

今が売り時か。

答え：物件による。

築10年の
駅近・利回り4%の物件なら
今のうちに売却推奨。

理由：築15年以降は
一気に買い手減。
金利上昇で購買力も落ちてるから
「今でしょ」が正解。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.9] 自宅購入型

家を買うときに誰も教えてくれないこと。

「返済比率35%以下」で
ローン借りたら危ない。

実際は
管理費・修繕積立金・固定資産税・保険
が別にかかる。

実質50%近い負担になる家庭も。

借りられる額 ≠ 返済できる額

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

余分な費用搾取されたりする。

15年投資やってわかったこと：
「ハコ買い」じゃなくて
「管理体制買い」が正解。

[No.11] 相続・贈与型

不動産×相続で揉める家族のパターン。

「親が投資物件持ってた」
「相続人が4人」
「誰が管理するか決まらない」

→ 物件が朽ちて
 負債化。

遺産分割調停→相続人全員で責任。

投資物件は
「生前対策」がないと
家族の火種になる。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.12] エリア選定型

この3つそろってるエリアは

逆に
人口流出してるエリアは
どんなに安くても買うな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.13] 金利・ローン型

住宅ローンと投資ローンの金利差。

投資用：4.0〜4.5%
自宅用：1.5〜2.5%

理由：銀行が「自宅は返す」と信じ、
「投資は返さないリスク」と判断するから。

だから投資ローンは
自宅ローンより金利で2%以上高い。

その差、年100万超。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか
