[No.1] 危険警告型

新築木造アパート。
利回り8%。
売主：デベロッパー。

これ、実は地雷物件なんだよな。

建築詐欺まがいの手口が多い。
「建築費は○○円です」と見積もるが、
実際は原価の1.5倍で請求される。

その差分が売主と施工業者の
キックバック。

完成後も雨漏り、クラック、
躯体の問題が5年で噴出する。

修繕費で利回りが2%に急落する。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.2] 業界本音型

不動産営業が「この物件いいですよ」
って言う物件ほど怪しい。

本当に良い物件は
営業が声かけする前に
内輪で消える。

なぜか。
粗利が低いから。

良い物件 = 相場価格
= 営業成績になりにくい

だから営業は
割高な物件、
問題がある物件、
回転率の悪い物件をプッシュする。

これが業界のリアル。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.3] 失敗談型

建築詐欺。
15年前、僕も引っかかった。

融資：8,000万
実際の建築費：4,500万

差分：3,500万が
建築会社と売主のポケットへ。

引き渡し後、基礎にクラック。
躯体が傾いてる。

修繕費に2年で800万投下。
利回りは消える。

今思えば、
複数の建築士に
現場確認させるべきだった。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.4] 初心者罠型

初心者が誤りがちなこと。

「表面利回り8%なら、
月々のキャッシュフロー（実際に手元に残る現金）
が安定する」

と思ってる。

違う。

空室が2ヶ月あれば
利回りは6%に落ちる。

固定資産税、火災保険、修繕費で
さらに1.5%吹き飛ぶ。

実質利回りは4.5%。
これが現実。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.5] 融資・ファイナンス型

融資を断られる人の共通点。

1. 預金が少ない
（最低でも購入額の15%必要）

2. 年収に対して
   既存ローンが多すぎる
   （返済比率が40%超）

3. 勤続年数が2年未満

4. 直近3年で転職してる

5. クレジットカードで
   リボ払いしてる

金融機関は
「この人、返せるか」
を数字だけで判断する。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.6] 利回りの罠型

表面利回り8%の物件。

これ、なぜ8%なのか。

答え：値段が安すぎるから。

なぜ安いのか。

理由は大抵、
・駅から遠い
・築古で修繕費がかさむ
・事故物件
・騒音

つまり、
「利回りが高い = リスクが高い」
は、ほぼ法則。

利回り6%で安心と、
利回り8%で毎年400万赤字。

後者がいる。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.8] 売却タイミング型

「今が売り時か」を判断する軸。

1. 金利が上がってるか
（上がってれば買い手が減る = 売り時）

2. 築年数が15年超か
（銀行融資が出にくくなる）

3. 賃料下落してないか
（下がってたら市場が冷えてる証拠）

4. 自分の年齢が65超か
（相続税対策で早めに処理）

1つでも当てはまれば
売却を真剣に検討すべき。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.9] 自宅購入型

自分の家を買う時に
誰も教えてくれないこと。

借入額の決定権は
金融機関にある。

あなたじゃない。

「年収の8倍まで貸します」
と言われたら
みんなそこまで借りる。

でも返せるのは
年収の5倍程度。

結果、40年間
毎月返済に追われる人生。

年収で判断するな。
手取りと支出で判断しろ。

[No.12] エリア選定型

なぜ、その駅の周辺は上がるのか。

答え：
再開発が決まってるから。

でも、駅前の再開発に気づいて
物件を買う奴は多い。

だから価格は既に上がってる。

狙うなら、
「再開発予定地の2駅隣」

ここが穴場。
恩恵を受けるが、
買値は安い。

これが不動産の正しい選定眼。

[No.13] 金利・ローン型

変動金利と固定金利。

変動金利は「今は安い」。
でも金利が上がる可能性がある。

0.5% → 3% になると、
月々の返済が20万増える人もいる。

固定金利は「今は高い」。
でも35年間、同じ返済額。

安さに飛びつく初心者が
変動選んで後悔してる。

借入額が大きいなら
固定一択。

[No.14] 問いかけ型

あなたは、なぜ不動産を買うのか。

「資産になるから」

本当か？

資産は「売れるもの」だけ。

売れない物件は
負債（将来の義務）だ。

買値5,000万の物件。
10年後、賃料が落ちて
売値は4,000万。

-1,000万の負債を
背負うだけ。

「資産」の定義、
改めて考えてみて。
