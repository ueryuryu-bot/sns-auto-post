[No.1] 危険警告型

「利回り8%って美味しくない？」

その物件、まじで危ないかもしれない。

新築木造アパートで表面利回り8%超。
でも実際は修繕費がバカにならん。
屋根・外壁・設備は15年で必ず来る。

積み立ててないと、その時点で赤字転換。
業者は言わないけど、それが業界の現実なんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

---

[No.2] 業界本音型

不動産営業マンが絶対に言わないこと。

「この物件、実は利付け（物件を魅力的に見せる）されてます」

新築は特にそう。
坪単価・利回り・立地説明は全部都合よく切り取られてる。

10億融資した俺が言うけど、
営業トークの70%は「その側面だけ抽出」なんだよ。

だから自分で数字を再計算する癖が必須。

推奨投稿時間：朝7時 / 昼14時 / 夜20時

---

[No.3] 失敗談型

建築詐欺で2000万吹っ飛んだ話。

施工会社が途中で倒産。
「資金不足で工事中断」って連絡来たのは竣工予定日の3ヶ月前。

銀行は「引き渡し時点での払い出し」だから、
その間の金利・税金・予定が全部狂った。

法的には勝ったけど、回収に3年かかった。

物件選びより「施工会社の信用調査」が実は一番重いんだよな。

推奨投稿時間：朝8時 / 昼12時 / 夜19時

---

[No.4] 初心者罠型

「新築アパート買いました！」

初心者あるある。

実は新築の時点で既に30～50万/戸の利益が組み込まれてる。
売主（ハウスメーカー）の利益だから、買った瞬間が最高値。

1年で2～3割下落するのはそのせい。

利回りで選ぶなら「築15年以上の中古」を目利きできる力がいる。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

---

[No.5] 融資・ファイナンス型

「融資が通らない」って相談受けるたび、
大体その人は同じ間違いしてた。

①年収の低さじゃなく、
  返済比率（年間返済額÷年収）を甘く見積もってる。

②金融機関は「現在の属性」じゃなく
  「今後のキャッシュフロー」で判断する。

手取りじゃなく「課税所得」で見られるのがミソ。

推奨投稿時間：朝10時 / 昼15時 / 夜20時

---

[No.6] 利回りの罠型

表面利回り10%に騙されるな。

実質利回り＝
（年間家賃－年間経費）÷購入価格

経費には以下が含まれる：
・管理費・修繕積立
・固定資産税・都市計画税
・火災保険・地震保険
・空室率（通常15～20%を見込む）

これ引くと、表面10%は実質5～6%になってたりする。

推奨投稿時間：朝8時 / 昼11時 / 夜22時

[No.7] 市場データ型

2025年、不動産市場は二極化が加速してる。

【上昇エリア】
駅徒歩10分以内、築20年以下
→ 3～5年で+15～20%

【下落エリア】
駅徒歩20分超、築30年以上
→ 3～5年で-10～15%

「不動産は下がらない」って時代は終わった。
ロケーション×築年数の組み合わせが全てなんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜20時

---

[No.8] 売却タイミング型

「今売り時ですか？」

その答えは「キャッシュフローがプラスか」で決まる。

キャッシュフロー黒字の物件は、
金利が上昇する局面では売った方がいい。
（理由：将来の買い手の融資が絞られるから）

逆にマイナスなら、
損失覚悟で売却するか、テナント入替で再生するか。

感情で判断してる投資家、多すぎなんだよな。

推奨投稿時間：朝7時 / 昼14時 / 夜19時

---

[No.9] 自宅購入型

自宅購入で誰も教えてくれないこと。

住宅ローン控除（年間最大40万円還付）の
対象期間は13年。

その後は返済額＝純粋な支出になる。

つまり「40代で家買った」なら、
返済完了時に控除が終わってるってわけ。

購入タイミングで手取り額が大きく変わるんだよ。

推奨投稿時間：朝8時 / 昼12時 / 夜21時

---

[No.10] 管理・運用型

物件を買った瞬間が、
実は スタートラインなんだよな。

その後の苦労：
・テナント募集（平均空室期間：3～6ヶ月）
・クレーム対応（給湯器・漏水・騒音）
・修繕手配（意外と業者探しで時間取られる）
・税務申告（計上漏れで税務調査のリスク）

「利回りだけで選んだ」人の離脱率、高いんだよ。

推奨投稿時間：朝9時 / 昼13時 / 夜20時

---

[No.11] 相続・贈与型

不動産が相続の時にモメる理由。

「時価と相続税評価額が全然違う」

時価5000万の物件でも、
相続税評価は3000～3500万になることがほとんど。

でも兄弟姉妹は「時価5000万」って思ってる。

土地は「路線価」、建物は「固定資産税評価」で決まる。
その差を知らずに遺産分割すると、揉めるんだよな。

推奨投稿時間：朝8時 / 昼15時 / 夜19時

---

[No.12] エリア選定型

「なぜ渋谷の物件は上がって、
  隣の原宿は下がるのか」

答え：駅の乗降客数と再開発フェーズの差。

渋谷は「スクランブル交差点周辺への企業集約」で、
今後10年の需要が確定してる。

一方、原宿は観光地化＆実生活需要の低下。

エリア選びは「統計」じゃなく「人流動向」を見るんだよ。

推奨投稿時間：朝10時 / 昼14時 / 夜21時

---

[No.13] 金利・ローン型

「金利0.5%の差」を甘く見るな。

3000万・30年ローンの場合：
金利3.0%vs3.5%＝総返済額で約250万の差。

借入時に少し頑張って、
金融機関や条件を比較するだけで数百万変わる。

0.1%単位で交渉する価値、まじであるんだよ。

推奨投稿時間：朝7時 / 昼11時 / 夜20時

---

[No.14] 問いかけ型

「その物件、自分で住みたいと思いますか？」

投資家の大半は「いいえ」って答える。

でも自分が住みたくない物件に、
他人が住んでくれると思いますか？

テナント難、空室長期化、値下がり圧力。

全部そこから始まるんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜19時

[No.15] 法改正・制度型

2025年から不動産の相続登記が義務化。

怠ると罰金10万円。

でも大事なのはそこじゃなく、
「登記費用が今後上がる」ってことなんだよ。

登記簿の整理＝相続準備＝早めにやる方が安い。

父親の物件を相続予定なら、
今年中に司法書士に相談した方が得なんだよ。

推奨投稿時間：朝8時 / 昼14時 / 夜20時
