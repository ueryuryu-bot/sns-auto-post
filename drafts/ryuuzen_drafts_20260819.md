[No.1] 衝撃ファクト型

有給を全部使い切ってる会社員、日本でたった15%らしいな。

つまり85%の人間が会社に時間を献上してる。
それで人生コントロールできてる奴、マジでいないんだよな。

俺も前はそっち側だった。
有給残して「評価のため」とか言ってた。
今は逆。使わないことが損だって気づいた。

推奨投稿時間：朝9時 / 昼12時 / 夜20時

[No.2] 逆張り意見型

「毎日頑張れ」って言葉、まじで嫌い。

頑張ってりゃ報われる時代、30年前に終わってんだよ。
今頑張ってるのって、ただ搾取されてることに気づいてないだけ。

俺が稼げるようになったのは頑張ったからじゃなくて、
頑張らない時間を作ったからなんだよな。

推奨投稿時間：夜21時 / 朝8時

[No.5] 比較対照型

【5年前の俺】
・朝6時起床、帰宅21時
・給料の奴隷
・休み = 休息（充電）
・人間関係は会社が全て

【今の俺】
・朝8時起床、帰宅18時
・複数収入源
・休み = 投資時間
・人間関係は自分で選ぶ

何が変わったって、時間の使い方。
その先に全部がついてくるんだよな。

推奨投稿時間：朝7時 / 夜22時

[No.10] 初心者向け解説型

「ノンキャリア」って何か簡潔に言うと、
会社に依存しない生き方。

別に起業することじゃなくて、
給料 + 副業 + 投資みたいに
複数の収入源を持つってだけ。

これだけで人生のコントロール権が戻ってくるんだよな。

推奨投稿時間：朝10時 / 昼14時

[No.11] 上級者向け洞察型

有給は「休む」じゃなく「投資」だと考えるやつが勝つ。

有給5日 ➜ 副業の準備時間
有給10日 ➜ 新しいスキル習得
有給15日 ➜ 事業構築

そして賢い奴は、
休職制度すら「年単位の投資期間」として使ってる。

会社が用意した制度を、会社の逆をついて使う。
それが戦略なんだよな。

推奨投稿時間：朝9時 / 夜19時

[No.15] ストーリー型

今は「店長」じゃなく「オーナー気質」で働いてる。
その変化を俺も見てきたんだよな。
