[No.1] 危険警告型

駅チカで新築木造アパート。
利回り8%超。めっちゃ魅力的に見えるんだよな。

でもまじで気をつけろ。
木造は築22年で融資がつかなくなる。

売却したくても買い手いない。
建築費が異常に高い案件ばっかり。

「新築だから安心」は不動産会社が言う、最強の嘘。

[No.2] 業界本音型

仲介手数料3%。
これ、誰が決めたと思う？

法律じゃなくて慣習。
実は1%でも交渉できるんだよ。

でも不動産会社は絶対言わない。
だって利益が減るから。

10年で100件取引すれば数千万変わる。
知らないだけで大損してる投資家、山ほどいる。

推奨投稿時間：朝8時 / 昼12時 / 夜20時のいずれか

[No.3] 失敗談型

建築詐欺に引っかかった時の話。

施工会社が勝手に工事を中断。
資金は既に振込済み。

弁護士立てて150万円の費用。
結局3年かかった。

あの時気付いたのは、
「いい人そう」で判断したこと。

現役不動産会社の兼業だった俺でもハマった。
初心者は特に気をつけろ。

推奨投稿時間：夜21時 / 夜22時

[No.4] 初心者罠型

「頭金ゼロで始められます」

この言葉で始める投資家の90%が失敗する。

なぜなら
キャッシュがない = リスク管理ができない

空室が2ヶ月続いたら資金繰り破綻。
修繕費が急に出たら詰む。

融資を引く能力と、生き残る能力は別なんだよな。

推奨投稿時間：朝9時 / 昼14時 / 夜20時のいずれか

[No.5] 融資・ファイナンス型

融資を断られる人の共通点。

1. 自己資金がない
2. 年収に対して借入が多すぎる
3. 返済比率が高い（年収の35%以上）
4. 勤続年数が短い
5. 税務申告と実際の所得が乖離してる

金融機関は「返せるか」だけ見てる。
夢や事業計画じゃ貸さない。

融資の目線でまず自分を評価してみろ。

推奨投稿時間：朝10時 / 昼13時 / 夜21時のいずれか

[No.6] 利回りの罠型

表面利回り8%と言われた。

でも計算してみたら
- 管理費3万
- 修繕積立2万
- 固定資産税1.5万
- 空室率10%見込み

実質利回りは4.2%。

表面利回りを信じたら、
ただのキャッシュポジショナーになる。

全ての経費を引いた数字で判断しろ。

推奨投稿時間：朝9時 / 昼15時 / 夜19時のいずれか

[No.7] 市場データ型

2026年の不動産市場。

新築マンションの平均価格、前年比+12%。
でも販売数は-18%。

つまり、高い物件だけ売れてる状態。
中堅層は完全に買い控え。

価格が上がってるのに買う人が減ってる。
これ、天井が近い合図なんだよな。

推奨投稿時間：朝8時 / 昼12時 / 夜22時のいずれか

[No.8] 売却タイミング型

「今が売り時か買い時か」

答えは簡単。

キャッシュフローがプラスなら買い。
マイナスなら売り。

市場の値段なんて二次的。
自分のポートフォリオ（資産構成）が基準だ。

周りが「上がるから買え」と言ってても、
お前のキャッシュが回ってなきゃ意味ない。

推奨投稿時間：朝10時 / 昼14時 / 夜20時のいずれか

[No.9] 自宅購入型

家を買うとき、銀行は年収の8倍まで貸してくれる。

年収600万なら4800万。

でも生活防衛費（手取り6ヶ月分）と
投資用の融資枠を考えたら、
本当は年収の4〜5倍が限界。

銀行の「貸せる金額」と「返せる金額」は全く別。

買う前に、自分の返済能力を冷静に見ろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.10] 管理・運用型

物件を買ったら、そこからが本当の仕事が始まる。

家賃管理、督促、修繕対応、
退去対応、クリーニング手配…

会社員の副業でこれを全部やるのは無理。

だから管理会社に払う。
月の家賃の5〜8%。

利回り8%と言われた物件は、実は管理費で2%飛ぶ。
リアルは6%なんだよな。

推奨投稿時間：朝10時 / 昼14時 / 夜19時のいずれか

---

[No.11] 相続・贈与型

親から不動産を相続するとき、
兄弟姉妹で揉めるパターン。

「現金で取得した不動産」と「ローンで買った不動産」じゃ
相続税の扱いが全く違う。

親が何もしないと、後で弟妹から訴えられる。

贈与する側は必ず税理士に相談してから。
贈与税・相続税・登記費用、全部計算しないと後悔する。

推奨投稿時間：朝11時 / 昼15時 / 夜20時のいずれか

---

[No.12] エリア選定型

「駅から徒歩7分だから大丈夫」

これ、地方と東京じゃ全く違う。

地方は「駅から徒歩10分以上は売れない」が常識。
東京は「駅から15分でも駅名が価値」。

同じ利回り7%でも、
東京なら資産価値が上がる可能性がある。
地方なら下がり続ける。

エリアで全て決まるんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.13] 金利・ローン型

住宅ローン1.5% vs 投資ローン3.5%。

「投資ローンは高い」と思うかもだけど、
家賃で返してるから実質利率は違う。

だけど、金利が0.5%上がるだけで
月の返済額が1万以上変わる。

固定と変動、どっちにするか悩むなら
今は固定一択。

金利上昇トレンドはまだ終わってない。

推奨投稿時間：朝8時 / 昼12時 / 夜21時のいずれか
