[No.1] 危険警告型

新築一棟アパート、めっちゃ危ない。

利回り8%とか見えてるけど、
実はローン返済後の手残りは3%未満。

建築詐欺はもちろん、
30年後に修繕費で100万超えることザラ。

買う前に「ローン完済後の現金流出」を
必ず計算しろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

---

[No.2] 業界本音型

不動産会社は「利回り」しか言わない。

なぜか。

「空室率」「修繕費」「税金」の話をすると、
買う人が減るから。

まじで、営業の話の8割は
「売主側の都合」なんだよな。

だから自分で数字を精査しない奴が
カモられる。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.3] 失敗談型

15年前、建築詐欺にあった。

施工会社が「建築品質基準」を無視して
手抜き工事。

壁の中身がスカスカで、
5年で200万の修繕費。

契約書には「瑕疵担保責任」（引き渡し後の不具合は売主責任）が
1年で消えてた。

素人判断で買うな。必ず建築士に検査させろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.4] 初心者罠型

投資初心者が沼るパターン。

「利回り10%あるから買おう」

でも実際は
・融資手数料 120万
・火災保険 15万/年
・管理費 30万/年
・修繕積立 50万/年

利回りは見た目の半分以下。

「表面利回り」じゃなく「実質利回り」を
自分で出せない奴は買うな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

---

[No.5] 融資・ファイナンス型

融資が通らない奴の共通点。

年収600万なのに既存ローン返済比率が45%超。

（返済比率＝年間ローン返済額÷年収。銀行は35%以下が目安）

金融機関は「その人に残る現金」で判断してんだよな。

追加融資前に既存ローンを圧縮しろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.6] 利回りの罠型

表面利回り8%の物件。

でも
・空室率10%想定で実質7.2%
・経費（税金・保険・管理）で実質4.8%

銀行ローン返済3.5%を引くと
手残り1.3%。

これで1,000万借りてる。
リターンに対してリスク大きすぎんだよ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.7] 市場データ型

2023年の賃貸住宅着工数は過去20年で最低水準。

→供給不足で賃料は上昇傾向。

だけど購入価格も同時に上昇してるから、
利回りは実は横ばい。

「供給減＝利回り上昇」じゃなく
「需給逼迫＝価格上昇」なんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.8] 売却タイミング型

不動産の売り時って実は数字で決まる。

「手残り現金流出＞売却益」になったら売却信号。

つまり
ローン返済5年目で修繕費が毎年100万超えるなら、
もう売る方が合理的。

感情で「まだ持ちたい」はマジで危ない。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

---

[No.9] 自宅購入型

家を買うとき誰も教えてくれないこと。

フラット35で0.9%金利だから
「安い」と思ってる奴、危ない。

35年で利息を足すと総返済額は1.3倍。
年1%の値上がりで相殺されて
実質利益ゼロだったりする。

買う理由を「投資」じゃなく「生活」にしろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

---

[No.10] 管理・運用型

物件買ってからが本当の苦労。

・空室対応で時間50時間/月
・クレーム対応で疲弊
・修繕業者との折衝

自分でやったら時給換算で赤字。

プロの管理会社入れると手数料8%飛ぶ。

つまり会社員の副業は
「管理のボリュームに気づかず潰れる」
パターン多いんだよな。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.11] 相続・贈与型

親から「不動産を相続する予定」って奴。

死ぬ前に親子で価格認識すり合わせてないと
揉める。

特に「親が評価額1,000万と思ってるけど
実勢価格600万」パターン。

相続税も修繕費も、兄弟で折半するなら事前調整しろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.12] エリア選定型

なぜそのエリアの家賃は上がるのか。

「駅まで徒歩10分だから」は理由にならん。

本当の理由は
・人口流入（転勤族・大学生増）
・都市計画（駅周辺再開発）
・企業立地（オフィス増）

この3つのうち2つ揃うエリアは
5年で家賃15%上昇の確度高い。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.13] 金利・ローン型

変動金利0.5%と固定金利1.5%。

「変動の方が安い」って思ってる奴多いけど、
5年後に金利上昇リスクがある。

融資総額10億なら金利1%上昇で
年間1,000万の返済増。

会社員の副業なら「固定金利」で
キャッシュフローを守るべき。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

ゴロゴロあるんだよな。

「立地」が全てだって気づかない奴が

今のうちに売却か相続対策しろ。
