[No.1] 危険警告型

「新築区分マンション買った」って言う会社員。
実は危ないんだよな。

建築詐欺見てきた俺から言うと、
新築区分は完成時に既に含み損。
売却時に1000万単位で損する人、
本当に多い。

利回り3%とか言われてるけど、
修繕積立金・管理費・税金差し引くと
実は赤字。気をつけろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時のいずれか

[No.2] 業界本音型

不動産会社は絶対に言わないけど、
物件の「本当の相場」って、
営業トークとは別の値段で動いてる。

売り手側の不動産会社と
買い手側の不動産会社で、
同じ物件の評価額が500万違ったりする。

なぜか。情報の非対称性だ。
プロだから相場を操作できるんだよ。

推奨投稿時間：朝8時 / 昼12時 / 夜20時のいずれか

[No.3] 失敗談型

俺が融資10億超えてた時、
ある物件で建築詐欺に引っかかった。

施工会社が勝手に予算を流用して、
完成時に「追加工事代金300万」って言われた。

契約書を舐めてた俺が悪い。
今は全案件で第三者監理を入れてる。

お前らはそこまで行く前に気づけ。

推奨投稿時間：朝7時 / 夜19時 / 夜22時のいずれか

[No.4] 初心者罠型

投資初心者が勘違いしてる「土地値」。

「この土地は坪100万だから安い」
→実は水道が来てない土地だったりする。

土地の価格には理由がある。
安い土地は「引き出しが難しい理由」がある。

その理由を調べずに買う奴、
マジで多い。

推奨投稿時間：朝10時 / 昼14時 / 夜21時のいずれか

[No.5] 融資・ファイナンス型

銀行が投資家に融資を断る理由、
大体これなんだよな。

・自己資金の割合が低すぎる
・他行の借入が多すぎる
・職業が不安定に見える
・物件のキャッシュフロー（月の手取り利益）がマイナス

融資って「見た目の収益」じゃなく
「返済後に残る金額」を見られてる。
そこ理解してない奴が融資難民になる。

推奨投稿時間：朝9時 / 昼12時 / 夜20時のいずれか

[No.6] 利回りの罠型

表面利回り8%の物件。
実際いくら手取りになるか計算したことある？

年間家賃200万だったら、
・管理費・修繕費 40万
・空室率（3ヶ月分想定） 50万
・固定資産税 25万
・火災保険 10万
→手取り は75万。
実質利回りは実は2.5%。

表面利回りだけ見てる奴、
投資じゃなくてギャンブルだ。

推奨投稿時間：朝8時 / 昼11時 / 夜19時のいずれか

[No.7] 市場データ型

2024年の首都圏マンション相場、
前年比で平均3.2%上昇してる。

だけど、
・築15年超→下落傾向
・駅遠（徒歩15分以上）→底値動き
・利回り2%台→売却難

全体が上がってるからって
どの物件も上がるわけじゃない。
個別の立地格差が広がってるのが今の市場。

推奨投稿時間：朝9時 / 昼13時 / 夜22時のいずれか

[No.8] 売却タイミング型

「今が売り時か」って質問よくもらうけど、
それ実は個人の事情で変わるんだよ。

相場が上がってても、
キャッシュフロー（毎月の利益）が必要なら
売るべきじゃない。

相場が下がってても、
金銭的に余裕ができたなら
売却して新しい物件に乗り換える判断もある。

相場より「自分の事情」優先でいい。

推奨投稿時間：朝10時 / 昼15時 / 夜20時のいずれか

---

[No.9] 自宅購入型

家を買う時、不動産屋は言わないけど、
住宅ローン控除（※毎年の所得税が戻る制度）
の計算、お前らやった？

年収500万の人と
年収1000万の人だと、
同じローン額でも戻ってくる金額が違う。

高給取りほど得する仕組み。
それを知ってる人は
ローン期間や金額を戦略的に組んでる。

推奨投稿時間：朝9時 / 昼12時 / 夜21時のいずれか

[No.10] 管理・運用型

物件を買ったら終わり、じゃなくて
そこから地獄が始まるんだよな。

家賃滞納者が出たら、
弁護士に連絡して（費用10万〜）
強制退去の手続き。

雨漏りしたら、
修繕業者の相見積もり。
相場より高い業者選ぶと50万無駄になる。

「買ったら儲かる」とか思ってる奴は
投資の1%も理解してない。

推奨投稿時間：朝7時 / 昼13時 / 夜20時のいずれか

[No.11] 相続・贈与型

親が不動産持ってる家庭、
相続で絶対揉める。

「この土地は誰がもらうのか」で
兄弟が10年音信不通になった話、
俺見てきた。

特に不動産は分割できないから、
現金より相続税対策が複雑になる。

親が生きてるうちに
遺言書と土地評価額の相談を
税理士と一緒にやっとけ。
後からじゃ遅い。

推奨投稿時間：朝8時 / 昼14時 / 夜19時のいずれか

[No.12] エリア選定型

「この駅周辺は発展する」って
不動産屋はいつも言うけど、

実は大事なのは「人口動向」なんだよ。
駅が新しくなっても、
その地域の人口が減ってたら
物件価格は下がる。

統計で見ると、
郊外の開発地って
5年後に人口が動かないケース多い。

駅近だからじゃなく、
「その地域に若い世代が流入してるか」
で判断しろ。

推奨投稿時間：朝9時 / 昼11時 / 夜21時のいずれか

[No.13] 金利・ローン型

住宅ローンと投資ローンの金利、
同じ銀行でも0.5%違ったりする。

これは銀行が
「投資は返済リスクが高い」と見なしてるから。

だから俺は最初、
自宅購入名目で金利2.5%で借りて、
後で投資物件に変更する奴もいる（※グレーゾーン）。

ただし、それがバレたら
一括返済求められるからな。
正規ルートで金利交渉する方が安全。

推奨投稿時間：朝10時 / 昼12時 / 夜20時のいずれか

[No.14] 問いかけ型

質問：
あなたが持ってる不動産、
「今売ったら幾らになる」って

大体の投資家は知らないんだよ。
買った時の金額の「なんとなく」で
持ってる。

売却価格を知らない投資家は
判断軸がない。
それって投資じゃなくて「タンス預金」。

推奨投稿時間：朝8時 / 昼13時 / 夜22時のいずれか

[No.15] 法改正・制度型

2024年から相続税の計算が変わった。
土地の評価額が上がったんだよ。

つまり、相続時にもらう不動産の
税負担が増えてる。

相続を予定してる人は、
今のうちに
「生前贈与」（親が生きてるうちに子に渡す）
で対策してる。

この制度、使わないと
後で100万単位で損する。
知ってる人はもう動いてる。
