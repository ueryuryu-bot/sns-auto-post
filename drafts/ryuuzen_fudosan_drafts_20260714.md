[No.1] 危険警告型

駅近・新築・高利回り。
その3つが揃った物件は「罠」だと思え。

新築は建設費が高い。
駅近は土地代が高い。
その両方を満たしながら高利回りを出すには、
建物の品質を落とすか、
売主の利益を削るしかない。

前者なら将来の大規模修繕で破綻する。
後者なら売主が潰れる。

どちらにせよ、
お前が買った時点で終わってる。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.2] 業界本音型

不動産会社は
「築20年の物件は危ない」とは言わない。

なぜなら、
彼らが仕入れてくる物件の大半が
築15〜25年だから。

言ったら自分たちの商品が売れない。

だからこそ、
「サステナビリティ」とか
「良好なテナント」とか、
耳心地いい言葉で包装する。

本当に見るべきは、
躯体（くたい＝建物の骨組み）と
修繕履歴だけ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.3] 失敗談型

15年前、
「表面利回り12％」という
新築アパートを買わされた。

売主は大手ゼネコンの関連会社。
「絶対安心」と言われた。

3年目で大規模修繕が必要に。
見積もりは1,500万円。

利回りは一瞬で3％になった。

後で知ったのは、
建築会社が利益を確保するため、
仕様を下げてたってこと。

「大手だから安心」は幻想。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.4] 初心者罠型

投資初心者が犯す最大の間違い。

「年収の3倍までなら融資が下りる」
って話を真に受けることだ。

金融機関は年収だけじゃなく、
既存債務・職歴・年齢・物件の担保力
を全部見てる。

「年収1,000万でも融資0円」
って人、山ほどいる。

逆に「年収600万でも3億」
って人もいる。

差は何か？
物件を見る目と、
既存資産の構成。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.5] 融資・ファイナンス型

銀行が「融資できません」という時、
理由は大体3つ。

①物件の担保力が低すぎる
（再販価値がない）

②キャッシュフロー（月の利益）が
ローン返済額を下回ってる

③お前の属性（年収・勤続年数・信用情報）
が弱い

このうち①は物件選びの失敗。
②③はお前の準備不足。

どれなら「物件のせい」と言える？
①だけ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.6] 利回りの罠型

「表面利回り8％」

これだけ見て買う奴、マジで多い。

表面利回り＝年間家賃÷購入価格

でも実際には、
管理費・税金・保険・修繕積立金
が引かれる。

実質利回り＝
（年間家賃−全経費）÷購入価格

この差が2〜3％あったりする。

表面8％でも実質5％。
ローン返済が年600万なら、
キャッシュは毎月赤字。

数字の粗さが人生を変える。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.7] 市場データ型

2024年、
東京23区の中古アパート価格は
前年比+8％。

でも平均築年数も
同時に+2年進んだ。

つまり古い物件ほど
値上がりしてるってこと。

これは新築着工数の減少が原因。

逆に言えば、
新築が出た瞬間に
周辺の中古は下がる可能性がある。

今買うなら、
その物件の「賞味期限」を
必ず意識しろ。

[No.8] 売却タイミング型

「いつ売るか」で利益は決まる。

買値で9割決まるけど、
売値で1割の差が出る。

今の相場は上昇局面だから、
持ってるだけで上がる局面。

でも、
金利が上がるたびに
購入希望者は減る。

5年保有で±0を狙うか、
3年で+20％を狙うか。

後者なら「今が売り時」だと
思ってる。

[No.9] 自宅購入型

家を買う前に誰も教えてくれないこと。

購入価格の15〜20％が
手数料・税金・登記代で消える。

3,000万の家を買っても、
銀行融資は2,400万くらい。
残りは自分で出す。

年収500万の家庭が
3,000万の家を買う理由が分からん。

返済負担率（年収に対するローン返済額）
が40％超える家族、
子どもの教育費が出て
どうなるか知ってる？

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.10] 管理・運用型

物件を買った瞬間から
本当の苦労が始まる。

テナント対応・修繕・空室対策・税務申告。

「管理会社に任せよう」って奴、
いるけど、

悪い管理会社を引くと
家賃の15〜20％が消える。

それでいて修繕は後回し。
5年で躯体がボロボロ。

結局、
自分で動く投資家ほど
利益を守れてる。

オーナーは経営者。
傍観者ではない。

[No.11] 相続・贈与型

不動産で揉める家族の
9割はここ。

「父が買った物件」を
相続税対策だと思って放置した結果、

子ども世代で
築30年、空室だらけ、
修繕費だけ年200万。

負債遺産だ。

相続税を「減らす」ことだけ考えて、
「運用」を忘れた典型例。

不動産は相続税対策ではなく、
生前に「売るか」「運用して利益化するか」
を決めておく資産。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.12] エリア選定型

「駅から5分」「人口増加地域」。

この2つがあれば
上がると思ってる奴、多い。

でも実際は、
駅から5分でも
商圏内の競合物件が
3年で10棟増えたら終わり。

価格競争で利回りが下がる。

大事なのは「相対的な需給」。

人口が増えてても
供給（新築）が増えてたら
空室リスクは上がる。

統計より「現地」を見ろ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.13] 金利・ローン型

住宅ローンと投資ローンは全然違う。

住宅ローン：
金利2.5％前後、返済期間35年

投資ローン：
金利4.5〜6.5％、返済期間20年

同じ1億でも年間利息は
1,500万円差が出たりする。

ここを無視して
「とにかく借りよう」って奴は
5年で破綻する。

金利上昇局面で
変動金利を借りるのは
自殺行為だと思っとけ。

推奨投稿時間：朝9時 / 昼13時 / 夜21時

[No.14] 問いかけ型

その物件、本当に
「値上がりする」と思ってますか？

それとも「キャッシュフロー（月利益）」
目当てですか？

9割の初心者は
「両方狙おう」と答える。

その時点で終わってる。

値上がり狙いなら、
キャッシュは赤字でいい。
キャッシュ狙いなら、
値上がりは期待しない。

両立させようとした瞬間に、
どっちも失敗する。

[No.15] 法改正・制度型

2025年から
建築基準法の省エネ基準が厳しくなる。

既存物件（築20年超）は
この基準外のまま。

つまり、
既存物件の価値相対的に下がる。

買うなら「適合物件かどうか」
が新しい物差し。

建築士に聞かずに買うな。

制度が変わる度に
物件価値は変わる。

「そういう時代」に
生で向き合えるのが
現役投資家の強みだ。
